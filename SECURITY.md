# Security

## Reporting a problem

Please report security problems privately, not in a public issue. Use the repository's **Security** tab, then **Report a vulnerability**. Only the maintainer sees the report.

## Participant data

This repository holds made-up data only. If you ever see something that looks like real participant or caregiver data in the code, an issue, a pull request or an export, report it privately straight away and do not copy it anywhere.

## What the app does with data

- Logs stay in the phone's browser storage (IndexedDB) until someone presses Export.
- Patients are pseudonymous codes, never names.
- The app has no server, accounts, analytics or third-party scripts.
